---
description: 生成本次维修工单（可直接登记/上报/交接）
---
请运行维修工单生成脚本，把本次的处理结果整理成可登记的工单：

```
powershell -NoProfile -ExecutionPolicy Bypass -File core\ps\ticket.ps1
```

脚本会基于 reports\ 下最新一次体检报告、ai_analysis.txt 与 logs\actions.log 自动生成工单，并询问位置、报修人、处理人。

生成后请：
1. 把工单内容完整显示给我；
2. 如果在本次会话中我补充了工单里没有的信息（例如故障现象、更换的耗材、后续待办），请把它们补进工单并重新保存；
3. 告诉我工单文件的确切路径，便于我打印或粘贴到学校的报修系统。
