对这台电脑做一次**只读快检**，不做任何修改：

1. 运行体检采集：
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File core\ps\collect.ps1 -Fast
   ```
2. 阅读 reports\ 下最新目录的 diagnosis.txt 与 findings.ini；
3. 用**三句话以内**给出结论：
   - 这台机器当前最值得注意的问题（按严重度）；
   - 是否影响正常使用；
   - 建议下一步做什么（如果要修，指出对应的 F 编号）；
4. 把结论追加保存到该报告目录的 ai_analysis.txt（UTF-8）。

不要执行任何修复动作，也不要改动系统设置。
