本次发布隔离已处理：公开构建不读真实配置、不复制历史副本；同步不遍历额外嵌套目录；新目标与哈希检查使复制失败不会由旧文件掩盖。普通启动入口默认不提权，管理员 VBS 能力保留供使用者显式选择；系统目录/磁盘路径改用 WINDIR/SystemDrive，避免依赖 C 盘。归档需本地启用配置，自动归档默认关闭，远程访问另行 opt-in；禁用 URL 拼令牌及 Token 参数，不打印服务失败内容。

已知供应链局限：现有本地运行时的文件存在不证明来自可信上游。离线依赖清单的 reviewed/noticesReviewed 是维护者审查声明，哈希保证复制一致性，不能证明软件本身安全。不能把秘密扫描结果当成不存在未知秘密的数学证明。

原目录凭据风险：`pi-home/agent/auth.json` 与 `logs/sync-backup-20261022-144035/pi-home/agent/auth.json` 检出秘密模式。未在当前原项目发现 `.git`，无法确认外部仓库/旧发布包是否已泄露；若曾提交这些路径，需使用者在独立流程中评估历史与轮换。此次没有改写历史、吊销账户或访问远程。
