# 候选版验证记录

本记录只针对 0.1.0-rc1 整理范围，不能解读为所有维修功能已验证。验证完成后填写最终结果；任何源码/清单变更需要重新执行对应检查。

静态验证：Windows PowerShell Parser ParseFile 检查所有 .ps1，不 dot-source/调用被检查脚本；Node --check 对权限扩展 TypeScript 只做语法检查；Python compile/配置 JSON/INI 结构、相对路径、模板映射与 SHA256 校验；VBS 使用临时副本在 Option Explicit 后插入无条件 WScript.Quit，WSH 全文编译后立即退出，原脚本主体未执行。原 GBK 批处理/VBS 编码保留；批处理入口只静态检查，不启动菜单或维修。

秘密/私人数据检查：读取配置与小文件内容并检查常见 Key/Token/私钥、含凭据 URL、个人绝对路径；原配置秘密值仅在内存比较，不写输出。检查遍及嵌套 logs 历史副本、sessions 与其他数据目录，候选只取明确源码/模板，不取运行数据。扫描工具仅报告文件位置/问题类型，未打印真实秘密。对未知格式或未列入规则的秘密不作绝对保证，正式公开前仍需复核。

发布边界验证：tests/packaging.ps1 仅调用新候选构建器/策略及修订后的同步 DryRun，所有输入来自候选生成的虚构测试副本。测试包括公开默认与 NoKey、Private NoKey、显式私人凭据、嵌套历史/额外文件、模板优先、已有目标拒绝、缺依赖/文件、哈希不符、路径穿越和同步 DryRun 无写入；从不调用维修、AI 或归档。构建不执行运行时、不下载、不请求管理员。临时目录和测试输出在完成后删除。

原件保护：整理前为非 runtime 原文件建立 SHA256 快照（包含嵌套数据），结束后比对。原 runtime 仅读取包元数据、许可证与 PE 签名/哈希；未复制/执行/修改它，未在原目录建立 Git 或写配置。
