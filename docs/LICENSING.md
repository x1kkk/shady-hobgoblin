# MIT 许可范围与来源确认

本地发布准备按维护者拟采用 MIT 的意向加入根目录 LICENSE，使用标准 MIT 正文。版权行采用 `Pi Agent Windows repair-tool contributors` 集体署名，未推定维护者的真实姓名、单位或网上账号。公开前维护者应确认该署名或改为希望公开的合法署名，并确认有权授权相应代码。

根 LICENSE 适用于本项目有权许可的原创脚本、扩展、测试、提示词、维修技能及文档；第三方代码、运行时、工具和原版权声明仍遵循各自许可证，见 THIRD_PARTY_NOTICES.md。MIT 不会替维护者取得未知来源代码的授权，也不对第三方商标或服务提供授权。

本轮复核：复用已有第三方盘点，检查候选中 57 个项目代码/文档文件的明显版权、许可和转载标记；未发现项目代码声明与 MIT 明显冲突的证据。报告中的“来源”字段是业务数据字段，不是代码来源声明。本次没有逐文件作者记录、贡献者协议或外部历史，因此“未发现冲突”不能视为完整权属鉴定。

公开前待维护者确认：

- 自有代码与技能/提示词是否自行编写或已有可再许可授权；是否包含雇主、客户或他人的受限内容。
- 如有复制/改编的第三方片段，提供来源及原许可，保留署名并单独标注其适用范围；若不能合法分发，应先处理该片段的授权问题。
- 集体版权署名是否合适，是否需要加入已有权利人的署名。

第三方依赖已有的版本、来源和许可材料缺口保持原记录。当前仅准备公开源码，不附这些待核实的工具二进制；以后组装便携发行包时再补齐实际分发组件所需的许可材料，不能将整个依赖目录统一改标 MIT。
